N-Day-Bench – Can LLMs find real vulnerabilities in real codebases?
⬆ 65 pts 💬 18 HN comments

N-Day-Bench is a sophisticated benchmark designed to evaluate the ability of frontier large language models (LLMs) to discover real-world software vulnerabilities, specifically 'N-Days' disclosed after the models' knowledge cut-off dates, thereby testing genuine cybersecurity capabilities rather than recall. It employs a rigorous, three-agent simulation framework: a Curator agent analyzes security advisories to build an answer key, a Finder agent (the model under test) is given 24 shell steps to explore codebases, starting from sink hints to trace vulnerabilities, and a Judge agent scores submissions blindly, ensuring no reward hacking. This benchmark is inherently technical, focusing on vulnerability discovery through actual code interaction, which moves beyond traditional static analysis by simulating real-world security researcher workflows. Its design addresses the critical gap in assessing LLMs' practical utility in cybersecurity, where models must reason about unknown threats, making it a pivotal tool for advancing AI-driven security research and model development.

In the latest run, the benchmark scanned 1000 advisories, accepting 47 cases, with top models like OpenAI's GPT-5.4 leading at an 83.93 average score, followed by Z-AI's GLM-5.1 at 80.13 and Anthropic's Claude-Opus-4.6 at 79.95, indicating varying but promising proficiency in vulnerability detection. The adaptive nature, with monthly updates to test cases and model versions, ensures relevance, while publicly browsable traces, such as those dated April 13, 2026, enhance transparency and reproducibility. Implementation details reveal an average of 1.07 findings per submission for GPT-5.4, suggesting cautious output, but comments highlight concerns about false positives and judge reliability. Societally, this benchmark could accelerate automated security auditing, but risks include over-reliance on LLM-generated insights without manual validation, potentially leading to noise in vulnerability management systems as AI integration deepens in cybersecurity pipelines.

OpenAI's GPT-5.4 leads N-Day-Bench with an 83.93 score, demonstrating the highest capability among frontier models in discovering real-world vulnerabilities post-knowledge cut-off.

The incident exposed critical flaws in the plugin marketplace: no oversight for ownership transfers, lack of change-of-control notifications, and implicit trust in update mechanisms. With 31 plugins permanently closed and hundreds of thousands of installations affected, this event underscores systemic vulnerabilities in open-source ecosystems, where economic incentives can override security, demanding a reevaluation of governance models and proactive defense strategies.

⬆ 708 pts 💬 373 HN comments

Rooted in concepts from tools like Phabricator and Gerrit, it allows developers to break monolithic diffs into smaller, focused layers that build sequentially. Each PR in the stack targets the branch of the previous one, with GitHub's UI providing a stack map for navigation and enforcing branch protection rules against the final target branch. This technical foundation leverages Git's branch mechanics but adds server-side intelligence to handle rebasing and CI integration, reducing merge conflicts and enabling incremental reviews without waiting for earlier layers to merge.
