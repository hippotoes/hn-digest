Monetization Gateway: Charge for any resource behind Cloudflare via x402
⬆ 302 pts 💬 212 HN comments

Cloudflare has announced the Monetization Gateway, a service that enables website owners to charge for any resource behind Cloudflare—web pages, APIs, datasets, or MCP tools—on a per-request basis using the x402 open protocol. The protocol leverages stablecoins for near-instant, low-fee micropayments, aiming to solve the long-standing problem of usage-based billing for unverified buyers. This is positioned as a response to the rise of AI agents, which do not engage with ads or subscriptions and generate massive, non-human traffic. Cloudflare will handle payment verification at the edge, offloading metering, exchange, and settlement from origin servers, allowing customers to set flexible payment rules via a rules API akin to existing Cloudflare rule expressions.

The gateway builds on last year's Content Independence Day and Pay Per Crawl initiatives, extending charge mechanisms from crawlers to any caller. Cloudflare claims sub-second settlement and support for variable pricing (e.g., $0.01 per request or up to $2 per image generation). The x402 protocol, now backed by the Linux Foundation's x402 Foundation with Coinbase, uses HTTP 402 responses and direct peer-to-peer stablecoin transfers, eliminating chargebacks. Critics worry about legal invoicing (mixedbit), the chicken-and-egg adoption problem (luhn), and the risk of making every interaction a toll (Animats). However, proponents see it as the missing infrastructure for an agent-first internet, where software automatically pays for content and APIs it consumes.

The Monetization Gateway: an engine that will give Cloudflare customers the ability to charge for any asset protected by Cloudflare: web pages, datasets, APIs, or MCP tools.

Key Highlights
  • Cloudflare Monetization Gateway enables per-request pricing for any resource behind Cloudflare using the x402 payment protocol and stablecoins.
  • Payments are verified at the edge, removing billing overhead from origin servers and enabling sub-cent transactions with sub-second settlement.
  • The service targets AI agents as primary buyers, since agents don't view ads or manage subscriptions, and can autonomously authorize micropayments.
  • Flexible rules allow charging based on HTTP verb, route, task complexity, or caller identity, with human users optionally exempted.
  • x402 Foundation (Linux Foundation, Coinbase) oversees the open protocol, which returns 402 Payment Required with payment instructions, then validates proof of payment.

For first time, a cell built from scratch grows and divides
⬆ 862 pts 💬 278 HN comments

For the first time, researchers have built a synthetic cell from nonliving components that can grow, replicate its DNA, and divide. Led by Kate Adamala at the University of Minnesota, the team combined a DNA replication system, a commercial transcription-translation mix, and feeder liposomes containing essential molecules like ribosomes and tRNAs, all enclosed in a lipid membrane. The key challenge—cell division—was solved by ditching the cytoskeleton and instead using protein tags that attract other proteins to crowd and bend the membrane, forcing the cell to split. This represents a significant step toward the holy grail of creating life from scratch, though the cell is not self-sustaining and requires constant feeding. The work integrates techniques from multiple labs, showcasing a systems-level approach to synthetic biology.

The synthetic cells, dubbed 'spudcells,' have a minimal genome that does not encode metabolic genes; instead, they rely on preloaded supplies delivered via membrane fusion. Remarkably, the cells showed signs of early evolution when researchers artificially created genetic variation—cells that grew larger produced more daughter cells, a first step toward natural selection. The team also launched Biotic, a nonprofit to make the tools and data open-source, aiming to accelerate research into biofuels, drugs, and origins of life. Critics note the cells still lack ribosome synthesis and a fully autonomous cycle, but as John Glass of the J. Craig Venter Institute remarked, this is 'a watershed event for the synthetic-cell field.' The work has sparked both excitement and healthy skepticism about what it means to build life.

"I think it will prove to be a watershed event for the synthetic-cell field and biology in general." — John Glass, J. Craig Venter Institute

The thread also revived comparisons with Opus, which at 64 kbps outperforms all AAC encoders, underscoring that AAC's strength remains widespread hardware support. The discussion reflects the tension between advancing legacy codec quality and the inevitable shift toward modern codecs like Opus, which already surpass them in efficiency.

The encoder is optimized only for 48 kHz and CBR; for 44.1 kHz audio and VBR mode, metrics are slightly lower but still leading.
