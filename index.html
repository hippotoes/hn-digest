CPU-Z and HWMonitor compromised
⬆ 321 pts 💬 89 HN comments

The CPUID website, a trusted source for system monitoring tools like CPU-Z and HWMonitor, experienced a sophisticated security breach from April 9-10, 2026, when attackers hijacked a secondary API component for approximately six hours. This compromise did not involve tampering with the signed software builds but manipulated download links to serve malware instead of legitimate executables. Technically, the attack exploited a backend vulnerability to randomly display malicious links, turning the site into a watering hole. The malware, identified as a credential stealer, targeted 64-bit HWMonitor users by deploying a fake CRYPTBASE.dll that mimicked legitimate Windows components, facilitating command-and-control communication to pull down additional payloads. This incident highlights the growing risk of API-level exploits in software distribution channels, where attackers can intercept downloads without compromising core software integrity, underscoring the need for robust backend security and monitoring.

Analysis by vx-underground revealed that the malicious installer leveraged infrastructure linked to earlier campaigns, such as those targeting FileZilla users, indicating a coordinated threat actor. The malware employed advanced evasion techniques, operating largely in memory via PowerShell to avoid disk-based detection, and compiled .NET payloads on victim machines before injection into processes. It specifically targeted browser credentials through Google Chrome's IElevation COM interface. CPUID confirmed the fix but provided no details on API access methods or affected user count. In Hacker News comments, users debated the broader implications, with some noting how false positives in antivirus software can lead to ignored warnings, while others discussed the security of package managers like winget. This event marks a shift in cybercriminal tactics from domain spoofing to direct compromise of official download mechanisms, raising critical questions about supply chain security and the adoption of verifiable build systems in an era of increasing digital trust erosion.

For six hours, a hijacked API on the CPUID site randomly served malicious links instead of legitimate downloads, turning trusted tools into a delivery mechanism for credential-stealing malware that operated in memory via PowerShell.

Specific applications, such as EUV lithography for chip production and fiber optics manufacturing, have no practical alternatives to helium, while others like welding and lifting gases can be substituted. The piece notes that while recycling and zero-boil-off technologies in MRI machines can reduce demand, helium usage in semiconductors is rising, exacerbating supply concerns. Societal impacts are significant, as shortages could impair medical diagnostics, technological progress, and scientific research, underscoring the need for improved recycling infrastructure and strategic reserves.

Liquid helium boils at just 4.2 kelvin (-452°F), making it the only practical coolant for superconducting magnets in MRI machines and critical semiconductor processes, with no viable substitutes in many applications.
