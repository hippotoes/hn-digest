NanoGPT Slowrun: 10x Data Efficiency with Infinite Compute
⬆ 142 pts 💬 29 HN comments

The NanoGPT Slowrun project achieves a 10x improvement in data efficiency for language models, using an ensemble of 1.8B parameter models (totaling 18B parameters) trained on merely 100M tokens to match the performance of a standard model on 1B tokens. This breakthrough directly addresses the scaling dilemma where compute growth outpaces data availability, potentially shifting the intelligence bottleneck from data to compute. By challenging Chinchilla scaling laws—which suggest a much smaller model for the same data—the work highlights the importance of architectural and algorithmic innovations in overcoming data constraints, with implications for more sustainable and scalable AI development.

Implementation details include ensembling with chain distillation, where models are trained sequentially with knowledge transfer, aggressive regularization such as weight decay set to 1.6 (16x higher than standard), and looping transformers that refine representations through iterative layers. Architectural tweaks like Exclusive Self Attention and value embeddings further contribute to gains. The societal impact is significant, as enhanced data efficiency could reduce reliance on massive datasets, democratize AI access by lowering resource barriers, and accelerate progress toward more autonomous and capable systems, with the team targeting 100x efficiency within a year.

10x data efficiency: an ensemble of 1.8B parameter models trained on 100M tokens achieves performance equivalent to a standard model on 1B tokens.

  • Achieved 10x data efficiency with NanoGPT Slowrun using ensemble methods
  • Leveraged chain distillation for sequential model training and improved generalization
  • Applied aggressive regularization techniques, including weight decay 16x above standard

Scaling Karpathy's Autoresearch: What Happens When the Agent Gets a GPU Cluster
⬆ 166 pts 💬 71 HN comments

Karpathy's autoresearch project leverages an autonomous coding agent to iteratively optimize a neural network training script by editing code, running experiments, and evaluating results within a fixed 5-minute training budget. Traditionally constrained to a single GPU, the agent employs sequential, greedy hill-climbing, which limits throughput and misses parameter interactions. This article explores scaling the system using SkyPilot, an open-source tool for managing cloud and Kubernetes resources, to provision a 16-GPU cluster. Parallel execution transforms the agent's strategy from serial trials to factorial grids, enabling simultaneous testing of multiple hypotheses and accelerating the discovery of optimal configurations through emergent adaptive behaviors.

Over an 8-hour session, the agent submitted approximately 910 experiments, reducing validation bits per byte (val_bpb) from 1.003 to 0.974—a 2.87% improvement. Key phases included hyperparameter sweeps, architecture discovery where scaling model width proved most impactful, fine-tuning, optimizer tuning, and diminishing returns. Notably, the agent autonomously developed a strategy to exploit heterogeneous hardware, screening ideas on H100 GPUs and validating on faster H200s, as noted in the article: 'the agent noticed that identical configs scored ~0.005 val_bpb lower on H200 clusters.' This demonstrates cost-effective autonomous research with potential societal implications for democratizing high-performance computing in AI development, though it raises questions about efficiency and novelty in automated experimentation.

With 16 GPUs, the parallel agent reached the same best validation loss 9x faster than the simulated sequential baseline (~8 hours vs ~72 hours).

Key Highlights
  • Scaling autoresearch from 1 to 16 GPUs enables parallel experimentation, shifting from greedy hill-climbing to factorial grids.

  • Emergent research strategy: autonomous exploitation of heterogeneous hardware, screening on H100s and validating on H200s.
