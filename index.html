Show HN: Sub-millisecond VM sandboxes using CoW memory forking
⬆ 147 pts 💬 37 HN comments

ZeroBoot introduces a novel approach to virtual machine sandboxing by leveraging copy-on-write (CoW) memory forking with Firecracker snapshots and KVM virtualization to achieve sub-millisecond spawn latencies. This technique involves creating a pre-booted VM template with a runtime, snapshotting its memory and CPU state, and then forking new VMs by mapping the snapshot as CoW memory, restoring CPU state in under a millisecond. This method provides hardware-enforced isolation per sandbox, addressing the need for rapid, secure execution environments in AI agent workflows, where traditional VM or container startup times are prohibitive for high-frequency tasks.

Benchmarks highlight impressive performance: 0.79ms p50 and 1.74ms p99 spawn latencies, with each sandbox consuming only ~265KB of memory, enabling high-density deployments such as 1000 concurrent instances on a single machine. The project includes SDKs for Python and TypeScript, facilitating integration into AI frameworks like LangChain or OpenAI Assistants. However, comments note challenges like entropy seeding for security and cross-node scalability. Despite being a prototype, ZeroBoot's architecture showcases potential to revolutionize sandboxed code execution for AI, reducing infrastructure costs and latency in agent-based systems.

Achieves 0.79ms median spawn latency with only 265KB memory per sandbox, enabling high-density concurrent executions for AI agents.

The Xbox One, launched in 2013 and long heralded as Microsoft's most secure product, has finally been compromised through a sophisticated hardware attack known as 'Bliss', unveiled at the RE//verse 2026 conference by researcher Markus 'Doom' Gaasedelen. This exploit leverages voltage glitching—a technique where precise manipulations of the CPU voltage rail induce faults in the boot process—targeting the silicon-level boot ROM to make it fundamentally unpatchable. The hack involves a double glitch: the first skips the initialization of ARM Cortex memory protection (part of the platform security processor), and the second hijacks a memcpy operation during header read, enabling full system compromise. This method bypasses traditional software defenses, highlighting the vulnerabilities inherent in hardware when attackers gain physical access, and represents a significant breakthrough in reverse engineering for a console that had remained unbreached for over a decade.

Gaasedelen noted that the Xbox One had 'some kind of iron curtain come down on security' since 2013, with Microsoft engineers once claiming it was 'the most secure product Microsoft has ever produced.' The Bliss exploit requires custom hardware tools to execute voltage glitches, emphasizing the challenges of defending against determined physical attackers. Data points include its impact only on the first revision of hardware, with later variants incorporating anti-glitching tech. Societally, this opens avenues for digital archivists to preserve firmware and games, potentially spurring emulation development, though the article suggests limited interest due to PC game overlap. The Hacker News discussion reflects deep technical analysis, with comments praising the hack's elegance while debating security philosophies and practical implications for older hardware and future console designs.

Gaasedelen says the attack is unpatchable, allowing for loading unsigned code at every level, including the Hypervisor and OS, and enables decryption of games and firmware via the security processor.

A Decade of Slug
⬆ 589 pts 💬 55 HN comments

The article details a decade of evolution for the Slug algorithm, a GPU-based rendering technique developed in 2016 that directly processes Bézier curves to render fonts and vector graphics without relying on precomputed textures. This approach prioritizes robustness by provably avoiding artifacts like dropped pixels, ensuring high-quality antialiasing and sharp corners at any scale or perspective. Developed initially for the C4 Engine to enhance text rendering in games, Slug has since been licensed widely across industries including video games, CAD, and medical visualization, leveraging its efficiency to maintain performance on consoles from 2016 onward. The technical foundation hinges on a winding number method for robustness, with iterative refinements over the years to optimize shader complexity and adapt to rendering challenges.

Key data points include its adoption by major clients like Activision and Adobe, with the HN story garnering 589 points and 55 comments. A pivotal update is the introduction of dynamic dilation, which automatically adjusts glyph bounding polygons in the vertex shader using model-view-projection matrices to eliminate aliasing and performance waste, derived from a complex quadratic equation. The author announces the dedication of patent #10,373,352 to the public domain, stating, 'I believe that holding on to it any longer benefits nobody,' and releases reference shaders on GitHub under the MIT license. This move is poised to impact the tech community by enabling free implementation, fostering innovation in text rendering for projects ranging from game development to open-source tools, while highlighting ethical considerations in software patenting.

Dynamic dilation automates optimal glyph bounding polygon expansion in the vertex shader, ensuring no aliasing artifacts or unnecessary GPU resource waste across varying text sizes and perspectives.

Technically, the preservation of these organic compounds in a carbonaceous chondrite asteroid underscores the role of space chemistry in generating complex biomolecules under conditions of low temperature and radiation, offering insights into prebiotic pathways that could be universal.

Data from the analysis reveals not only nucleobases but also sugars like ribose and glucose, as cited in comments referencing NASA findings. #9
Edge.js: Run Node apps inside a WebAssembly sandbox
⬆ 137 pts 💬 37 HN comments

Edge.js is a novel JavaScript runtime from Wasmer designed to run Node.js applications within a WebAssembly sandbox, addressing key limitations of traditional container-based isolation. By leveraging WASIX (WebAssembly System Interface), it sandboxes only unsafe components—system calls and native modules—while keeping the JavaScript engine (V8, JavascriptCore, or QuickJS) native for performance. This architecture preserves full Node.js compatibility (targeting v24) without requiring code modifications, contrasting with edge runtimes like Deno or Cloudflare Workers that introduce new APIs. The approach aims to reduce startup times and increase density in serverless environments, positioning Edge.js as a potential bridge between Node's ecosystem and the security demands of edge computing and multi-tenant hosting.

Performance benchmarks show Edge.js operates within 5-20% of native Node.js speed when sandboxed, with plans to close this gap in future releases. A compatibility table reveals it passes 3592 out of 3626 Node.js spec tests, outperforming alternatives like Bun and Deno in core modules. The project was developed in weeks using AI tools like GPT-5.4 and Codex, significantly accelerating what would have taken years. This innovation could transform how developers deploy AI agents and edge workloads, reducing reliance on heavy containers while maintaining safety. However, it shifts trust boundaries from the OS kernel to the runtime layer, raising questions about adversarial resilience in high-concurrency scenarios.

Edge.js passes 3592 out of 3626 Node.js spec tests, achieving near-perfect compatibility while sandboxing unsafe parts via WebAssembly, a stark contrast to runtimes like Deno or Bun that struggle with module support.

#12
Show HN: Pgit – A Git-like CLI backed by PostgreSQL
⬆ 22 pts 💬 8 HN comments

Pgit introduces a novel Git-like CLI that leverages PostgreSQL as a backend, transforming git history into a SQL-queryable database through a custom storage engine called pg-xpatch. This innovation centers on delta compression, where consecutive file versions are stored as differences, achieving median compressions as low as 2 bytes per change, as detailed in the underlying xpatch library. By moving version control from filesystems to relational databases, pgit enables complex historical analyses without parsing git logs, addressing a gap in automated codebase introspection. The project stems from the creator's exploration of delta compression applications in databases, positioning pgit as both a benchmark tool and a practical solution for engineering teams seeking to mine repository data programmatically, with implications for storage efficiency and query flexibility.

Benchmarking against git gc --aggressive on 20 real repositories (273,703 commits), pgit outperformed in 12 cases, such as compressing serde by 30% and tokio by 7%, while losing on repositories like prettier due to git's cross-file deduplication. Key use cases include coupling analysis to reveal hidden dependencies and churn detection for maintenance hotspots, facilitated by built-in commands like 'pgit analyze coupling' and raw SQL queries. The article highlights an AI agent integration where Claude Opus produced a full codebase health report in under 10 minutes from a single prompt, demonstrating pgit's potential to enhance agent capabilities by providing structured, queryable history. This shift could democratize advanced codebase analytics, reducing reliance on custom tooling or expensive services and fostering more data-driven development practices.

In benchmarks, pgit outcompresses git gc --aggressive on 12 out of 20 repositories, while making the entire commit history SQL-queryable, enabling AI agents to analyze codebases in under 10 minutes.

Key Highlights
  • Pgit is a Git-like CLI backed by PostgreSQL with automatic delta compression via pg-xpatch.
  • It allows SQL queries on git history for analyses like coupling, churn, and bus factor without parsing logs.
  • Benchmarks show pgit compresses better than git gc --aggressive on 60% of tested repositories.
  • AI agents can use pgit to generate codebase health reports efficiently, as demonstrated with Claude Opus.
  • Built-in commands provide common analyses, with an SQL escape hatch for custom queries.
